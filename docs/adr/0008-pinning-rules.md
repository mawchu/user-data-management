# 0008 釘選列的位置規則

- 狀態：採用
- 階段：4 畫面

## 背景
需求：使用者可以選一列，把它釘在指定位置。之後不論怎麼排序，它都留在那個相對位置。

## 決策
- 釘選資料存成 `Map<id, 目標位置>`。查詢時，先把釘選列排除，排序其餘的列，再把釘選列插回各自的位置。
- 目標位置超過資料量時，依序排在最後面。例如搜尋後只剩 3 筆，釘在第 100 列的那一筆會顯示在第 4 列。
- **搜尋不符合的釘選列不顯示**：搜尋就是篩選，顯示不相符的列會讓人困惑。
- **同一個位置只能釘一筆**：重複釘選回 409，避免兩筆搶同一列時順序不明確。
- 釘選或取消釘選後，從頭重新查詢。

## 代價
- 如果需求其實是「釘選列永遠顯示」，要改一行篩選條件。
- 要換位置，得先取消原本的釘選。

## 驗證
- `tests/db.test.ts`：在每一種排序下，釘選列都在指定位置，其餘資料仍然照排序規則。
- e2e：把 #13 釘在第 3 列之後，切換 Age、User name、Date Start 的升降冪，它都還在第 3 列。
