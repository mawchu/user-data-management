# 0017 手機改成固定高度的卡片

- 狀態：採用
- 階段：4 畫面

## 背景
題目要求桌機 1920×1080 和手機 375×667 都能使用。原本表格的最小寬度是 1090px，手機上只能左右捲動，而且看不到操作按鈕。

## 決策
- 寬度 640px 以下改成卡片，一筆一張，用 CSS grid 重新排列同一組欄位，不另外寫一個元件。
- 卡片高度固定 124px：虛擬捲動和 DOM 回收的計算方式不用改，只是列高從 44 變成 124（`UserTable.vue` 用 `matchMedia` 切換）。切換版面時，換算成同一列的捲動位置。
- 手機沒有表頭可以點，在頁首加上排序選單，一樣可以排序 5 個欄位的升降冪。

## 代價
- 卡片高度固定，欄位內容太長時會被截斷，加上省略號。

## 驗證
e2e 在 375×667 下確認：
- 頁面和列表都沒有左右捲動。
- 卡片高度是 124px，表頭隱藏。
- 用排序選單選 Age 降冪，結果正確。
- 編輯視窗完整顯示在畫面內。
